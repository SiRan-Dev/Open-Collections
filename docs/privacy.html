Open Collections 隐私政策

最后更新：2026-11-03 · 适用于 Open Collections 浏览器扩展

Open Collections（以下简称「本扩展」）是一个本地网页收藏工具。本政策说明本扩展会处理哪些信息、信息存放在哪里，以及会与谁共享。

1. 我们不收集你的数据

本扩展不含账号系统、分析统计、广告 SDK、遥测或远程代码。开发者不会收到你的任何数据，也不会将其出售或共享给第三方；只有你主动配置的 WebDAV 服务器或 AI 接口会收到你主动发送的数据。

2. 本扩展在本地处理的信息

仅当你主动操作时，本扩展才会处理以下信息，且全部保存在你本机的浏览器存储（chrome.storage.local）中：

  • 你收藏的网页：标题、网址、站点图标、收藏时间
  • 你保存的摘录：选中文字、来源标题与网址
  • 你填写的笔记、分组名称与颜色
  • 扩展设置，包括启用 WebDAV 时填写的服务器地址、用户名与密码，以及启用 AI 整理时填写的接口地址、API Key、模型名称与分类表；其中用户名、密码与 API Key 经本机自动生成的保险库密钥加密后保存
  • AI 分类缓存（内容哈希与分类结果），仅保存在本机，用于避免重复调用接口

3. 网络访问

  • 站点图标：通过浏览器内置的 _favicon 接口读取，不向站点或第三方发起额外请求。
  • 摘录：只在你点击「摘录」或使用摘录快捷键（默认 Ctrl+Shift+E）时，读取当前页面中你选中的文字；不会读取页面其他内容。
  • WebDAV 同步：只在你点击「测试连接」「立即同步」「仅上传」「仅下载」，或你主动开启「定时自动同步」后，向你自己填写的 WebDAV 服务器发起请求。数据与凭据只会发送到该服务器。
  • AI 整理：只有你在设置中启用 AI 整理并点击「AI 整理」或「测试连接」时，才会向你自己填写的 OpenAI 兼容接口发送当前整理范围的分组/集锦名称、卡片标题（最多 80 字）、域名、笔记（最多 60 字）与摘录片段（最多 100 字），以及用于认证的 API Key。开发者不会收到这些数据；请自行确认该接口运营方的隐私与数据处理政策。
  • 除上述情况外，本扩展不发起任何网络请求。

4. 权限用途

  • storage：保存分组、卡片与设置
  • sidePanel：显示侧边栏界面
  • tabs：读取标签页标题与网址，用于收藏当前页与批量收藏本窗口标签
  • activeTab / scripting：在你点击「摘录」或按快捷键时读取当前页选中文字
  • favicon：显示站点图标
  • alarms：在你开启定时同步后进行计时
  • 可选的主机权限（<all_urls>）：默认不授予，仅在你点击「摘录」，或使用 WebDAV / AI 时按需申请对应站点的访问权限

5. 数据的保存与删除

  • 数据保存在本机浏览器存储中；卸载扩展会清除全部本地数据。
  • 你可以在界面内随时删除分组或卡片，也可以用「导入 JSON（覆盖）」替换全部数据。
  • 若启用 WebDAV，云端副本存放于你自己的服务器，由你自行管理与删除。

6. 你的权利与撤回

  • 导出：设置页可导出 JSON 与 HTML 书签，导出内容不包含任何凭据或密钥。
  • 删除：可随时删除分组/卡片，或覆盖导入清空本地数据；卸载扩展会清除本地存储。
  • 撤回同意：AI 整理与 WebDAV 同步默认关闭，只有你首次启用并确认后才生效；关闭开关会立即停止后续请求，WebDAV 还会停止定时任务并取消进行中的同步。
  • 本扩展不会出售、出租你的数据，也不将其用于广告、画像或与功能无关的用途。

7. 凭据安全与传输

WebDAV 服务器地址与 AI 接口地址仅接受 https://，保存时即校验并拒绝明文 http。WebDAV 用户名、密码与 AI 接口的 API Key 使用本机自动生成的随机 256 位保险库密钥（经同样随机生成的本机设备密钥封装后存于浏览器存储）以 AES-GCM 加密保存；磁盘不保存明文，整个使用过程无需输入任何密码，同步或 AI 请求时只在内存中临时解密。该措施能降低浏览器存储被离线读取（如拷贝浏览器配置、备份泄露）时的泄露风险，但不能防御已能读取本机浏览器配置或扩展内存的恶意程序/扩展（设备密钥与保险库记录在同一存储中），也不能替代系统磁盘加密。若担心本机被他人使用，请不要启用同步或 AI 整理，或使用专用的低权限账号 / 应用专用密码。

8. 儿童隐私

本扩展不是面向儿童的产品，也不会有意处理儿童的个人信息。

如本政策发生变化，会更新本页面顶部的日期；重大变更会在扩展设置页或商店更新说明中提示。

Privacy Policy

Open Collections (the "Extension") is a local web-page collection tool. This policy explains what information the Extension processes, where it is stored, and with whom it is shared. Last updated: 2026-11-03.

1. No developer collection or sale

The Extension has no accounts, analytics, advertising SDKs, telemetry, or remote code. The developer receives none of your data and never sells, rents, or shares it for advertising, profiling, or unrelated purposes. Only the WebDAV server or AI endpoint you explicitly configure receives data you choose to send.

2. Information processed and stored locally

Only when you take an action, the Extension processes the following, stored entirely in your browser's local storage (chrome.storage.local): titles, URLs, site icons and timestamps of pages you save; selected text of excerpts and their source title/URL; notes you write; group names and colors; settings including https WebDAV/AI endpoint addresses, model name, category list, and WebDAV username/password and AI API key encrypted with a locally generated vault key; and a local AI classification cache (content hashes and category results) used to avoid repeated API calls.

3. Network access

  • Site icons are read through the browser's built-in _favicon interface; no extra requests are made.
  • Excerpts read the text you selected on the current page only when you click "Excerpt" or use the excerpt shortcut (default Ctrl+Shift+E).
  • WebDAV sync is disabled by default. After you enable it and confirm the first-use notice, it contacts only the https server you configure, and only when you click test/sync/upload/download or enable scheduled sync. Disabling it stops scheduled jobs and cancels an in-progress sync.
  • AI organization is disabled by default. After you enable it and confirm the first-use notice, it contacts only the https OpenAI-compatible endpoint you configure, and only when you click "AI Organize" or "Test connection". It sends the current group names, card titles (up to 80 characters), domains, notes (up to 60 characters), excerpt snippets (up to 100 characters), and the API key used for authentication. The developer receives none of this data; check the privacy practices of your AI provider.
  • No other network requests are made. Plain http endpoints are rejected when saving and when making requests.

4. Permissions

storage to save data and the local vault record; sidePanel for the sidebar UI; tabs to read tab titles/URLs for saving and batch-collecting; activeTab/scripting to read your selection on demand; favicon for site icons; alarms for scheduled sync only when you enable it. The optional host permission (<all_urls>) is not granted by default and is requested only when you use excerpts, WebDAV, or AI.

5. Retention, export, deletion, and withdrawal

  • Data stays in local browser storage and is removed when the Extension is uninstalled.
  • You can delete groups or cards at any time, or replace all data via overwrite import.
  • You can export JSON or HTML bookmarks from the settings page; exports never include credentials or keys.
  • Cloud copies, if any, live on your own WebDAV server and are managed by you.
  • AI and WebDAV are opt-in and can be disabled at any time. Disabling stops new requests; disabling WebDAV also stops scheduled jobs and cancels an in-progress sync.

6. Credentials and transport security

WebDAV and AI endpoint addresses must use https://; plain http is rejected. WebDAV username/password and the AI API key are encrypted with AES-GCM using a random 256-bit vault key generated on your device (itself wrapped by a random device key, both stored in browser storage). Plaintext credentials are never written to disk, no password is ever required, and secrets are decrypted in memory only when a sync or AI request is made. This reduces the risk of offline reads of browser storage (copied profiles or leaked backups), but it cannot protect against malware or malicious extensions that can already read your browser profile or the Extension's memory — the device key and vault record live in the same storage, and the vault is not a TPM — and it does not replace full-disk encryption. Do not save credentials on a device you do not trust.

7. Children

The Extension is not directed to children and does not intentionally process children's personal information.

8. Changes

If this policy changes, the date at the top of this page will be updated; material changes will be noted in the Extension or the store update notes.

      设置

      概览

      常规

      收藏与设置仅保存在本机浏览器存储；AI 整理与云同步默认关闭，启用后才会联网。分组栏折叠状态按「侧边栏 / 独立窗口」分别记忆，可点顶栏按钮切换。

      收藏与去重

      关闭时收件箱条目不会参与 AI 自动归类，避免被动搬动；在收件箱视图内主动点击「AI 整理」仍会执行。

      关闭时按规范化 URL 跨分组查重（忽略协议、末尾斜杠与 utm_* 等跟踪参数）；命中后会提示所在分组，并可选择仍然添加。同一页面的不同摘录不受影响。

      开启「每日收件箱」后，批量收藏按本地日期收进「收件箱 · 每日标签页」，当天多次收藏合并到同一组。单页收藏与摘录仍进当前分组。

      AI 整理

      未启用：AI 整理可以按固定分类把收藏自动归组，默认关闭、启用后才联网。

      API Key 经本机密钥加密后保存在本地 chrome.storage。整理时会把当前范围的标题、域名、笔记与摘录片段发送到你填写的接口，不会发送给其他第三方； 请求前才临时解密。

      启用后才会调用接口；首次启用会展示发送内容、目标与截断长度，确认后才写入启用状态。关闭后会立即停止后续请求。修改以下任意配置会即时保存。

      AI 只能从这些分类中选择；「其他」始终保留作为兜底，表外结果会归入其中，已有同名主题集锦会直接复用。分类表变化会使旧缓存失效；命中缓存的条目不会再次发送给 AI。

      云同步（WebDAV）

      未启用：可把收藏与设置同步到你自己的 WebDAV 服务器（如 Nextcloud），默认关闭、启用后才联网。

      凭据经本机密钥加密后保存在本地 chrome.storage，不会上传给任何第三方（仅用于向你自己的 WebDAV 服务器认证）。 同步时只在内存中临时解密。

      启用后才会发起网络请求；首次启用会展示发送内容与目标，确认后才写入启用状态。关闭后会立即停止定时任务并取消进行中的同步。

      收藏与分组、设置项始终同步；WebDAV 凭据、AI API Key 与本地密钥永不同步。远端结构带版本号（openpocket/v2），版本不兼容时会停止同步并说明原因，不会强行覆盖。

      本地加密

      检测到旧版「主密码」加密的数据。请输入一次旧主密码完成迁移，之后不再需要任何密码； 也可以暂时跳过（凭据暂不可用，可随时回来重试或重新填写）。

      凭据（WebDAV 用户名/密码、AI API Key）使用本机自动生成的 256 位保险库密钥做 AES-GCM 加密， 密钥经本机设备密钥封装后保存在浏览器存储中，启动时自动解封，无需输入密码。 这能防止直接读取浏览器存储拷贝或备份时泄露明文； 不能防御已能读取本机浏览器配置或内存的恶意程序/扩展，也不能替代系统磁盘加密。 若无法信任当前设备，请不要保存凭据。清除本地密钥会删除全部已加密凭据且不可恢复。

      快捷键

      扩展无法写入浏览器快捷键，修改只能在浏览器快捷键页面完成。Windows/Linux 显示 Ctrl 系，macOS 显示 Command 系； manifest 中的 suggested_key 只是建议值，实际绑定以浏览器为准。 点击工具栏图标即可打开侧边栏（Chromium 无关闭 API，关闭请手动点面板右上角 ✕）。

      数据管理

      覆盖导入会先自动备份当前数据到本地存储。合并导入按条目 ID 冲突时取较新者。

      设置导出包含全部设置项与「已配置/未配置」状态标记，不含任何凭据、API Key 或本机专属值；导入前会显示差异预览并自动备份，可合并或覆盖。

      删除分组或卡片后可从「查找并清理重复链接」等入口产生的本地备份恢复；卸载扩展会清除全部本地数据。

      关于

      Open Collections · 本地集锦管理。数据存放于浏览器 chrome.storage.local。

      快捷键绑定以浏览器为准，可在本页「快捷键」区查看当前绑定，或在浏览器快捷键页修改。

      编辑卡片

      AI 整理方案

      未修改任何内容；可重试，或先关闭后手动整理。

      查找并清理重复链接

      只清理网页卡片；摘录按「来源 URL + 选区文本」判定，不参与此清理。执行前会自动生成一份本地备份。

      启用前确认

      只有你确认后才会写入启用状态；之后可随时在设置中关闭，关闭后不再发起新请求。

      选择要收藏的窗口

      默认选中最近活跃的窗口；固定标签与浏览器内部页会被跳过。

      导入设置

      「合并」只应用文件中出现的设置项；「覆盖」还会把文件中未出现的设置项恢复为默认值。两种方式都不会改动 WebDAV 凭据与 AI API Key。应用前会自动备份当前设置。
